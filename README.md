# منصة التدريب الذكي

منصة تدريب عربية مبنية على **Firebase**، وتستخدم **Claude** لتقديم مدرّب ذكي وتوليد الاختبارات والدورات.

## الميزات

### مسار المهارات
البرنامج مقسّم إلى **11 مهارة** تظهر كلها للمتدرب، وتُفتح بالتسلسل: لا ينتقل إلى المهارة التالية إلا إذا اجتاز **الاختبار البعدي** للمهارة الحالية بنسبة يحددها المشرف من **لوحة التحكم** (افتراضياً 70%، ويمكن تحديد نسبة خاصة لكل مهارة). يُصحَّح الاختبار البعدي في الخادم، وإجاباته محفوظة في مجموعة `courseKeys` التي لا يقرؤها المتدرب، وعند الرسوب لا تُكشف الإجابات الصحيحة.

كل مهارة تمرّ بست مراحل: **التعريف والأهداف ← فيديو إنفوجرافيك بصوت عربي وموسيقى ← إنفوجرافيك قابل للتنزيل ← أمثلة واقعية مصوّرة ← الدروس والمهام التطبيقية ← الاختبار البعدي**.

### قوالب العرض
يختار المتدرب أحد **6 قوالب** (زمرّد، ليل، رمال، محيط، بنفسج، ورق)، ولكل قالب ألوانه وخطه وأشكاله وموضع القائمة وترتيب صفحة المهارة (مسار رأسي، بطاقات، تبويبات) وشكل خريطة المهارات. يُحفظ الاختيار في حسابه. الخطوط مستضافة داخل الموقع (لا تعتمد على Google Fonts).

| الميزة | ماذا تفعل |
|---|---|
| **دورات ودروس** | دورات قصيرة، لكل درس محتوى وأسئلة. تأتي المنصة بثلاث دورات جاهزة (Python، التواصل الفعّال، الأمن السيبراني). |
| **اختبار تكيّفي** | يقدّر مستوى المتدرب في كل مهارة (نظام شبيه بـ Elo) ويختار السؤال التالي بحيث تكون فرصة النجاح قرابة 70%: لا سهل مملّ ولا صعب محبِط. |
| **مراجعة متباعدة** | كل سؤال يخطئ فيه المتدرب يدخل صناديق لايتنر، ويعود إليه بعد يوم ثم 3 ثم 7 أيام… حتى يثبت. |
| **المدرّب الذكي** | محادثة مبثوثة مباشرة مع Claude، تعرف محتوى الدرس الذي يدرسه المتدرب. زر «اشرح لي أكثر» بعد أي سؤال يفتح المدرّب ومعه السؤال وإجابة المتدرب. |
| **اختبار ذكي** | يكتب المتدرب موضوعاً أو يلصق نصاً (محاضرة، سياسة عمل…) فيولّد Claude اختباراً منه ويُحفظ في حسابه. |
| **إنشاء الدورات (للمشرفين)** | يصف المشرف الدورة والفئة المستهدفة، فيبني Claude دروسها ومحتواها وأسئلتها وتُنشر فوراً. |
| **تحفيز** | نقاط خبرة، مستويات، سلسلة أيام، نسبة إتقان لكل مهارة، ولوحة صدارة. |

```
  src/engine.js          محرّك التعلّم التكيّفي (دوال نقية مع اختبارات)
  src/store.js           قراءة وكتابة Firestore

```

**نموذج البيانات في Firestore**

- `courses/{skillId}` — المهارة: التعريف، والوسائط، والدروس، وأسئلة الاختبار البعدي **دون إجاباتها**.
- `courseKeys/{skillId}` — إجابات الاختبار البعدي وشروحها؛ للمشرف والخادم فقط.
- `settings/platform` — نسبة النجاح للانتقال، وهل الانتقال متسلسل.
- `users/{uid}` — تقدّم المتدرب: النقاط، السلسلة، المهارات، الدروس المكتملة، وقائمة المراجعة.
- `users/{uid}/attempts` — سجل المحاولات. `users/{uid}/quizzes` — الاختبارات المولّدة (تكتبها الدوال فقط).
- `leaderboard/{uid}` — الاسم والنقاط والمستوى لعرض لوحة الصدارة.
- `usage/{uid}_{date}` — عدّاد طلبات الذكاء الاصطناعي اليومية (للخادم فقط).

مفتاح Claude API لا يصل إلى المتصفح أبداً: يُحفظ في **Secret Manager** وتستخدمه الدوال السحابية فقط، وكل دالة تتطلب تسجيل الدخول.

## التشغيل المحلي (دون مشروع Firebase حقيقي)

المتطلبات: Node.js 22، وJava 11 أو أحدث (لمحاكي Firestore)، وFirebase CLI:

```bash
npm install -g firebase-tools
```

```bash
npm run install:all
```

ضع مفتاح Claude للمحاكي (الملف مستثنى من git):

```bash
echo "ANTHROPIC_API_KEY=sk-ant-..." > functions/.secret.local
```

شغّل المحاكيات في نافذة:

```bash
npm run emulators
```

وفي نافذة ثانية ارفع الدورات ثم شغّل الواجهة:

```bash
npm run seed:local
```

```bash
npm run dev
```

افتح `http://localhost:5173` وأنشئ حساباً. واجهة المحاكيات على `http://localhost:4000`.

لتجربة صفحة الإدارة محلياً، امنح حسابك صلاحية المشرف ثم سجّل الخروج والدخول:

```bash
FIREBASE_AUTH_EMULATOR_HOST=127.0.0.1:9099 node functions/scripts/set-admin.js --project demo-smart-ai you@example.com
```

## النشر على Firebase

1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com) وانقله إلى خطة **Blaze** (الدوال السحابية وSecret Manager يتطلبانها).
2. فعّل **Authentication** ← طرق الدخول: البريد/كلمة المرور وGoogle.
3. أنشئ قاعدة **Firestore**.
4. أضف تطبيق ويب، وانسخ إعداداته إلى `web/.env.local` (انظر `web/.env.example`).
5. اكتب معرّف مشروعك في `.firebaserc` بدلاً من `your-firebase-project-id`.
6. احفظ مفتاح Claude سرّياً (من [Claude Console](https://platform.claude.com)):

   ```bash
   firebase functions:secrets:set ANTHROPIC_API_KEY
   ```

7. انشر كل شيء (يبني الواجهة تلقائياً):

   ```bash
   npm run deploy
   ```

8. ارفع الدورات الجاهزة وعيّن المشرف (يحتاجان صلاحيات Google Cloud محلياً، مثل `gcloud auth application-default login`):

   ```bash
   node functions/scripts/seed.js --project <project-id>
   ```

   ```bash
   node functions/scripts/set-admin.js --project <project-id> admin@example.com
   ```

## التكلفة والإعدادات

- النماذج: `claude-haiku-5-5` للمدرّب وتشغيل برومبتات المتدربين، و`claude-sonnet-5-5` للتصحيح الذاتي وتوليد الاختبارات، و`claude-opus-5-5` لإنشاء الدورات (نادر). غيّرها من `MODELS` في `functions/src/claude.js`.
- لكل متدرب حد يومي لطلبات الذكاء الاصطناعي، افتراضياً **60** طلباً. غيّره بالمعامل `DAILY_AI_LIMIT` (يسألك عنه `firebase deploy` أول مرة، أو ضعه في `functions/.env`). إنشاء الدورات للمشرفين فقط ولا يُحسب ضمن الحد.
- عند رفض النموذج طلباً لأسباب تتعلق بالسلامة، يعيد الخادم تشغيله تلقائياً على نموذج بديل مناسب (`fallbacks: "default"`).

## إنتاج وسائط مهارة جديدة (على نمط المهارة الأولى)

1. اكتب `content/skill-XX/skill.json` و`video.json` و`infographic.json` على غرار المهارة الأولى.
2. ولّد التعليق الصوتي (ElevenLabs، صوت «رزان» للفصحى التعليمية) وضعه في `raw/narration.mp3`، وتوقيت الكلمات في `raw/words.json`، والموسيقى في `raw/music.wav` ومؤثر الانتقال في `raw/whoosh.mp3`، والصور في `raw/`.
3. شغّل الأدوات:

   ```bash
   npm --prefix content/tools install
   ```

   ```bash
   node content/tools/render-video.mjs content/skill-XX
   ```

   ```bash
   node content/tools/render-infographic.mjs content/skill-XX
   ```

4. أضف المهارة في `content/skills.json` وشغّل `seed.js`، أو أدخلها من محرّر المهارات في لوحة التحكم.

للمعاينة السريعة قبل الرسم الكامل: `PREVIEW="6,40,90" node content/tools/render-video.mjs content/skill-XX`.

> **ترخيص الموسيقى:** الموسيقى ومؤثر الانتقال في فيديو المهارة الأولى من مكتبة أصوات HeyGen. تحقّق من شروط استخدامها التجاري خارج HeyGen قبل الإطلاق، أو استبدلها بموسيقى مرخّصة.

## حدود معروفة في هذه النسخة

- تُحسب النقاط والتقدّم في المتصفح وتُحفظ في وثيقة المتدرب، فيمكن لمستخدم متمرّس التلاعب بنقاطه في لوحة الصدارة. لمنصة بشهادات رسمية، انقل التصحيح واحتساب النقاط إلى دالة سحابية.
- الإجابات الصحيحة للأسئلة موجودة في وثيقة الدورة التي يقرؤها المتدرب.
- المحتوى المولّد بالذكاء الاصطناعي يُنشر مباشرة؛ راجعه قبل اعتماده رسمياً.
